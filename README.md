Smart Meeting Summarizer

-An AI-powered meeting assistant that converts meeting audio into text and automatically generates useful meeting insights.

-The application uses Faster-Whisper for speech-to-text transcription and Ollama with Llama 3.2 for AI-powered meeting analysis.

## Features

-  Upload meeting audio/video files
-  Automatic speech-to-text transcription
-  AI-generated meeting summaries
-  Extract key decisions
-  Extract action items
-  Identify action-item assignees
-  Identify deadlines when mentioned
-  Professional React dashboard
-  FastAPI backend
-  Local AI processing with Ollama
